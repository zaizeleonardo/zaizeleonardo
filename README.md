### 🚀 Projeto em destaque

#### [Conecta+ API](https://github.com/zaizeleonardo/conecta-plus-api)
API REST que conecta candidatos e empresas e calcula a **compatibilidade entre o perfil do candidato e a vaga**, apontando competências que faltam e recomendando cursos.

- Java 21 · Spring Boot · Spring Security · JWT · MySQL
- Perfis de candidato, empresa e administrador com controle de acesso
- Documentação com Swagger, testes com JUnit/Mockito, Docker e CI no GitHub Actions
- **Em produção:** API no Railway e [frontend em React na Vercel](https://conecta-plus-front.vercel.app)

Análise de documentos jurídicos com Python e IA: extração de entidades (nomes, datas, valores, cláusulas) com spaCy e resumo automático com Transformers.
